# V3 独立样例

四个项目登记为四个不同仓库。Java/Python checkout 各 18 项测试，三组独立知识：缺失/空白文本、数值格式/范围、索引边界/空集合，各组两个相关缺陷。原始源码故意保留缺陷，修复答案只在后端测试夹具中。

booking 各 12 项测试。其业务合同不同：姓名回退 visitor，非法格式数量回退 1，数量范围 1..30 且越界抛错，无法选择时返回 unassigned。共享 capability 只表示输入机制，不表示业务默认值相同。通用规则必须在目标测试下重新验证。

验收在受控副本中运行原始失败、部分修复仍失败、完整修复通过，并确认源目录指纹不变。单条经验不能复制或人工拆分成多条；V3 验收由生产提取接口直接接收一个含多条独立规则的模型响应。
