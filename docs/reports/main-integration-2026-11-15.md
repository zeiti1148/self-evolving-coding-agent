## 合并时发现并修复的兼容问题

原上传项目的版本指纹包含宿主应用的 Git HEAD，保存代码提交后，上传源码未变而旧授权被误判过期。现仅真正 Git 根包含 HEAD，并以严格解析的源码 tree 身份兼容旧指纹。仓库和 runner 精确匹配，显式业务契约不放宽；源码变化、测试配置变化、证据变化和新审阅仍会拒绝旧授权。无需改写历史原始经验、冲突关系或恢复授权。

Windows 默认 Python 3.13 未启用 UTF-8 模式时，Git 输出的中文路径会被按 GBK 解码。Git 子进程现在显式使用 UTF-8，并用实际非 UTF-8 模式的 Python 子进程验证中文 Git 根目录。

评测使用只读冻结库中的已验证规则，并按规则身份验证实际模型请求，支持同一来源的多条问题规则。脚本模式实际运行 HTTP API、Maven、pytest 和 SQLite，但模型响应受控；这些结果用于验证执行链，不算真实模型效果实验。
