# 测试源码直接链接验收（2026-11-01）

## 完成内容

任务“最终结果”和每个测试步骤增加“查看测试源码”。独立源码页面支持 Java/Python、文件切换、行号、复制文件直达链接、刷新恢复、返回任务及深浅色主题，沿用现有页面风格。

新增两个只读 API，使用任务持久化请求和工作副本归属记录定位文件，只允许任务创建时已有的测试源码。逐次读取时核对 SHA-256，保留缩进和换行，拒绝已改动文件、任意路径和新添文件。读取不会创建任务、工具步骤或模型调用。接口约定见 [接口文档](../interfaces.md)，操作见 [演示说明](../demo.md)。
