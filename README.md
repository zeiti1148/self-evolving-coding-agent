# 具备自演化能力的 Coding Agent 系统设计与实现

## 项目背景

本项目是软件工程学院中级实训与综合实训的连续开发项目，由三名成员共同完成。项目以 Coding Agent 为研究与实践对象，探索大语言模型在软件工程任务执行、经验积累与能力演化方面的应用。

当前仓库处于基础工程初始化阶段，本文描述的是项目规划，不代表相关功能已经实现。

## 项目目标

项目计划设计并实现一个能够辅助完成编程任务的 Coding Agent 系统。系统将逐步具备任务管理、代码操作、工具调用、测试执行与经验记录能力，并在后续阶段探索经验提炼、复用、验证和效果评估机制。

## 暂定技术栈

- 后端：Python、FastAPI
- 前端：Vue 3
- 数据存储：SQLite
- 智能能力：大语言模型 API
- 版本管理与协作：Git、GitHub

技术选型将在开发过程中根据需求进一步验证和调整。

## 中级实训开发目标

中级实训阶段计划完成 Coding Agent 的基础原型，主要包括：

- 核心执行引擎
- 代码文件操作
- 工具调用
- 自动化测试执行
- 任务管理
- 基础经验记录

本阶段目标是形成能够实际执行编程任务的系统原型，并为后续演化机制提供基础。

## 综合实训开发目标

综合实训阶段计划在基础原型上继续开发自演化机制，主要包括：

- 经验提炼
- 技能复用
- 经验验证
- 经验与技能的版本管理
- 自演化效果评估

本阶段目标是形成具备初步自演化能力的 Coding Agent 系统，并通过可重复的实验评估演化效果。

## 三人协作方式

三名成员将通过 Git 和 GitHub 进行协作：

- 使用 Issue 记录需求、任务和问题
- 按模块或功能划分开发任务
- 在独立分支上完成开发，避免直接在 `main` 分支进行功能开发
- 通过 Pull Request 进行代码审查和合并
- 提交信息保持清晰、简洁并反映变更目的
- 重要设计方案与阶段报告统一存放在 `docs/` 目录
